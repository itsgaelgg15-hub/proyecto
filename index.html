ESTRUCTURA WEB

HTML: ESTRUCTURA DE LA PAGINA WEB

HTML significa HyperText Markup Language, o lenguaje de marcado de hipertexto. Sirve para organizar el contenido de las páginas web mediante etiquetas.

Etiquetas HTML comunes

Etiqueta
Función
Ejemplo
<h1>
Título principal
<h1>Hola</h1>
<p>
Crear párrafos
<p>Texto</p>
<a>
Crear enlaces
<a href="#">Visitar</a>
<img>
Insertar imágenes
<img src="foto.jpg">
<ul>
Crear listas desordenadas
<ul>...</ul>

Estructura básica de HTML

<!DOCTYPE html>
<html lang="es">
<head>
    <title>Mi sitio web</title>
</head>
<body>
    <h1>Hola, mundo</h1>
    <p>Mi primera página web.</p>
</body>
</html>

DISEÑO DE LA WEB

CSS: DISEÑO Y PRESENTEACION

CSS significa Cascading Style Sheets, u hojas de estilo en cascada. Se utiliza para cambiar colores, tamaños, espacios y distribución de los elementos de una página web.

¿Qué son los selectores CSS?

Los selectores permiten elegir los elementos HTML a los que se aplicarán los estilos.

Selector
Función
Ejemplo
p
Selecciona los párrafos
p { color: blue; }
.clase
Selecciona una clase
.caja { padding: 10px; }
#id
Selecciona un identificador
#inicio { text-align: center; }
*
Selecciona todos los elementos
* { box-sizing: border-box; }

Ejemplos básicos de reglas CSS

body {
    font-family: Arial, sans-serif;
    background-color: #f4f7fb;
    color: #243247;
}

h1 {
    color: #8054C7;
}

.caja {
    border: 1px solid #d8e1ee;
    padding: 20px;
    border-radius: 12px;
}

PROGRAMACIÓN

JavaScript

JavaScript es un lenguaje de programación que permite agregar interactividad a los sitios web. Puede responder a clics, mostrar mensajes, validar formularios y modificar el contenido de una página.

Conceptos básicos

Concepto
Descripción
Ejemplo
Variable
Guarda un valor
let nombre = "Ana";
Función
Realiza una tarea
function saludar() {}
Condición
Evalúa una expresión
if (edad >= 18) {}
Evento
Responde a una acción
click

Ejemplo de código JavaScript

function mostrarMensaje() {
    alert("¡Hola! Gracias por visitar mi sitio.");
}

Este ejemplo muestra cómo una función puede generar un mensaje cuando se ejecuta. En este proyecto se presenta únicamente como contenido informativo.

ACTIVIDADES

Ejemplos desarrollados

Estos ejemplos muestran algunas actividades básicas que se pueden realizar al desarrollar páginas web.

Lista ordenada de actividades

  1. Crear una página con títulos y párrafos.
  2. Insertar imágenes y enlaces.
  3. Aplicar estilos mediante CSS.
  4. Agregar elementos interactivos.

Lista desordenada de recomendaciones

  • Utilizar etiquetas HTML correctamente.
  • Separar los estilos en un archivo CSS.
  • Agregar texto alternativo a las imágenes.
  • Probar el sitio en distintos dispositivos.
